## Principios de trabajo

1. **Auditable antes que impressive.** Si no se puede verificar, no se publica.
2. **Privacidad primero.** Offline-first y sin telemetria por defecto.
3. **Documentacion como producto.** Cada repo explica que es y **por que** existe.
4. **Sin secretos.** Gitleaks con historial completo en CI.
5. **Una fuente de verdad.** Un solo lockfile, una sola configuracion, un solo tema.
